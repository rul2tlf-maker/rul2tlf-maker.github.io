# rul2tlf-maker.github.io

这个仓库是 `rul2tlf-maker` 账号下所有独立 GitHub Pages 的根入口。

目标：

- 给用户一个统一入口
- 给 Google 一个稳定可抓取的根 Page
- 统一承接 `中国 eSIM`、`中国内地可用 eSIM`、`香港 eSIM 中国能用吗`、`中国 eSIM 热点共享` 等搜索意图

## 后续维护规则

以后这个账号下每新增一个独立 page，都要同时做 3 件事：

1. 把新页面链接补到根 Page 首页
2. 把新页面 URL 补进根 `sitemap.xml`
3. 保持描述性锚文本，不要只写“点击查看”

## 主题方向

后续优先覆盖这些核心搜索词：

- 中国 eSIM
- 中国内地可用 eSIM
- 香港 eSIM 中国能用吗
- 中国 eSIM 热点共享
- 香港号码 eSIM

`VPN`、`梯子` 等词保留在辅助解释层，不作为总站主标题。
